# Unobtainium — сайт для GitHub Pages

## Файлы
- `index.html` — структура сайта
- `style.css` — оформление и адаптация под мобильные устройства
- `script.js` — переключение RU/KZ/EN и мобильное меню

## Публикация на GitHub Pages
1. Создайте новый публичный репозиторий, например `unobtainium-site`.
2. Загрузите в корень репозитория три файла: `index.html`, `style.css`, `script.js`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/unobtainium-site/`.

## Важно перед публикацией
Это стартовый дизайн-макет. Проверьте у представителей Unobtainium:
- официальное написание названия и логотип;
- точный список услуг;
- адрес, телефон, email и график работы;
- фотографии, лицензии, сертификаты и юридические формулировки;
- разрешение на публикацию материалов и использование бренда.

В `index.html` замените демонстрационные контакты, а в `script.js` при необходимости отредактируйте переводы.
