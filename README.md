# UNOBTAINIUM — сайт учебно-экспертного центра

Статический сайт для GitHub Pages: https://nezerteam.github.io/unobtainium.io/

## Файлы
- `index.html`, `about.html`, `services.html`, `training.html`, `documents.html`, `contacts.html` — страницы
- `style.css` — оформление и адаптация под телефоны (мобильное меню, форма, кнопка WhatsApp — в конце файла, блок «v2»)
- `script.js` — переводы KZ/EN, переключение языков, мобильное меню, форма заявки
- `favicon.svg` — иконка во вкладке браузера
- `og-image.png` — картинка, которую показывают WhatsApp, Telegram и соцсети при отправке ссылки

## Как устроены языки
Русский текст написан прямо в HTML. У каждого переводимого элемента есть атрибут `data-i18n="ключ"`,
а казахский и английский варианты лежат в `script.js` в объекте `I18N` под тем же ключом.

Чтобы поправить перевод: найдите ключ в HTML (например, `data-i18n="hero_title"`) и измените
текст под этим ключом в `I18N.kz` или `I18N.en`. Выбранный язык запоминается в браузере посетителя.

## Форма заявки
Форма не требует сервера: по кнопке открывается WhatsApp (номер +7 778 090-11-06) с готовым сообщением —
имя, телефон, компания, услуга и комментарий. Номер задан в атрибуте `data-wa` формы и в ссылках `wa.me`.
Ссылка вида `contacts.html?service=srv_audit#request` открывает форму с выбранной услугой.
